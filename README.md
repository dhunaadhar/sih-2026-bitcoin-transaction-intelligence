# SIH 2026 - AI-Powered Monitoring & Analysis of Bitcoin Transaction Traffic

Final implementation for Smart India Hackathon 2026 Problem Statement 26146.

## Problem Statement

AI-powered offline monitoring and analysis of Bitcoin transaction traffic with correlation between blockchain-layer and network-layer metadata.

## Core Capabilities

- CSV, JSON and XML ingestion
- Schema validation, normalization, deduplication and provenance tracking
- Bitcoin transaction and wallet feature engineering
- Network-layer IP/port/timing analysis
- Entity resolution and entity clustering
- Unified IP-wallet-transaction graph
- Graph features and embeddings
- Supervised machine learning
- Unsupervised anomaly detection
- Peeling-chain and mixing-pattern detection
- Behavioral pattern detection
- Risk scoring and graph-based risk propagation
- Explainable AI and ranked alerts
- Dashboard and investigative link analysis
- Structured logging and health monitoring
- Failure and crash notification
- Offline Linux deployment
- AppImage distribution

## Data

The original Elliptic++ dataset is maintained outside this repository at the shared project data location. Large raw datasets are not committed to Git.
